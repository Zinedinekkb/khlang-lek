# คลังเหล็ก — สต็อกสินค้า (Khlang-Lek)

ระบบบริหารจัดการสต็อก ขายสินค้า การเงิน และออกเอกสารสำหรับร้านค้าเหล็ก (Vanilla JS + Vite + Firebase Firestore + Vercel)

## 🚀 ลิงก์ระบบใช้งานจริง
- **Website:** [https://khlang-lek.vercel.app](https://khlang-lek.vercel.app)
- **Database:** Google Cloud Firestore (`jin-replit1` / คลังเหล็ก - สต็อกสินค้า)

---

## 🛠 ฟีเจอร์หลัก
- **สต็อกสินค้า:** ติดตามจำนวนเส้น/แผ่น/ท่อน, น้ำหนักรวม (กก.), มูลค่าสต็อก, แจ้งเตือนของใกล้หมด
- **แบ่งขาย / ตัดเหล็ก:** Cut Planner คำนวณตัดจากท่อนเหลือหรือเส้นเต็ม บันทึกเศษเหล็กอัตโนมัติ
- **ซื้อเข้า:** บันทึกรับซื้อเหล็กเก่า / ซื้อเหล็กใหม่ แนบรูปใบเสร็จ บันทึกค้างจ่าย/ครบกำหนด
- **ขายด่วน & ออกเอกสาร:** ขายหน้าร้าน, จดออเดอร์, ออกใบเสนอราคา / ใบเสร็จรับเงิน / ใบส่งของขายเชื่อ, QR พร้อมเพย์
- **การเงิน & ปิดงวด:** บันทึกรายรับ-รายจ่าย, สรุปกำไร-ต้นทุน, ปิดยอดเงินสดประจำวัน
- **เครื่องคำนวณ:** คำนวณน้ำหนักเหล็กตามรูปทรงและเกรด, คำนวณราคาขายต่อ กก.
- **สำรองและกู้คืนข้อมูล:** ส่งออก/นำเข้า Excel, สำรองข้อมูลทั้งหมดเป็น JSON และกู้คืนไฟล์ได้ตลอดเวลา

---

## 💻 การรันในเครื่อง (Local Development)

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. รันโหมด Development
npm run dev

# 3. ตรวจสอบการ Build
npm run build
```

---

## 🔄 การอัปเดตระบบ (CI/CD Auto-Deploy)
เมื่อทำการแก้ไขโค้ดและ Push ขึ้น GitHub:
```bash
git add .
git commit -m "ข้อความอธิบายการแก้ไข"
git push origin main
```
Vercel จะตรวจพบและทำการ Deploy อัปเดตขึ้น [https://khlang-lek.vercel.app](https://khlang-lek.vercel.app) ให้โดยอัตโนมัติทันที
